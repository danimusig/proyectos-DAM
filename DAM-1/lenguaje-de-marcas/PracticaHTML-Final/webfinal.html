Sobre Mi

Hola! Soy un apasionado de la tecnología en constante aprendizaje y actualmente estoy dando mis primeros pasos profesionales como estudiante en prácticas en STEMDO. Mi objetivo durante esta etapa es transformar la teoría en soluciones reales, sumergiéndome en un entorno de desarrollo profesional y colaborativo. Durante mi estancia en STEMDO, estaré potenciando mis habilidades técnicas en las tecnologías que mueven el sector.

  • Desarrollo Frontend: Perfeccionando el diseño y la estructura web con HTML5, CSS3 y la interactividad dinámica de JavaScript.
  • Backend y Datos: Profundizando en la lógica de negocio con Java y el manejo eficiente de bases de datos mediante SQL.
  • Low-Code & Innovación: Explorando el potencial de Appian para optimizar procesos empresariales de forma ágil.
  • Colaboración: Integrando GitHub en mi flujo de trabajo diario para un control de versiones profesional y trabajo en equipo.

Soy una persona curiosa, orientada a la resolución de problemas y con muchas ganas de aportar valor mientras aprendo de los mejores profesionales del sector. ¡Ganas de código y de nuevos retos!

Tecnología Descripción
HTLM

Define una estructura básica y un código para la presentación de contenido de una página web, que incluye texto, imágenes, videos, juegos, entre otros elementos.
CSS

Es un lenguaje informático especializado en definir y cohesionar la presentación de un documento escrito en un lenguaje de marcado.
JavaScript

Es un lenguaje de programación interpretado, dialecto del estándar ECMAScript. Se utiliza principalmente del lado del cliente, implementado como parte de un navegador web permitiendo mejoras en la interfaz de usuario y páginas web dinámicas
